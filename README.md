# Pumpkin Problem Escape Room – background music

This public repository hosts the soundtrack for the Pumpkin Problem game on Neocities.

## Setup

1. Upload `Tim-Burton-Inspired-Dark-Fantasy.mp3` to the repository root using **Add file → Upload files → Commit changes**.
2. In **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)** and save.
3. Wait for the GitHub Pages site to become available.

Expected music URL:
`https://chipieambrosia.github.io/pumpkin-problem-escape-room/Tim-Burton-Inspired-Dark-Fantasy.mp3`

The Neocities HTML game should use that URL as its audio source.
